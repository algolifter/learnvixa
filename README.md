# LEARNVIXA

Create a fully animated AI-powered CBSE Class 12 study website designed as a complete Board Exam Preparation System.

Website Name: Study Command Center

CORE PURPOSE:

Help a CBSE Class 12 student deeply understand concepts, generate exam-perfect notes with neat diagrams, predict board questions, track study progress, reduce stress, and maximize board exam performance.

The website must feel like a professional AI study dashboard, not a simple notes website.

Use smooth animations, modern UI, dark mode support, mobile responsiveness, and distraction-free design.

--------------------------------------------------

1. MAIN DASHBOARD (FIRST PAGE – GAME STYLE)

--------------------------------------------------

Design a powerful, motivating, animated dashboard including:

• Board Exam Countdown Timer (Days Remaining)

• Overall Progress Tracker (0% to 100%)

• Subject-wise Progress Bars

• Daily Study Goal Section

• Study Streak Counter (continuous study days)

• Study Time Tracker (hours studied)

• Quick Revision Button

• Smart AI Study Planner (based on exam countdown)

• Weak Chapter Detection (AI-based)

• Motivational Quote Section (dynamic)

• Calm Mode Button (for stress relief)

Subject Cards (with icons and animations):

• Mathematics

• Physics

• Chemistry

• Computer Science (Show “Content Coming Soon” and DO NOT display chapters)

• English Core

7. PERFECT NOTES SYSTEM (TOPPER-LEVEL NOTES)

--------------------------------------------------

When Notes is clicked, generate structured, exam-perfect notes including:

• Chapter Overview

• Word-perfect Definitions (keyword highlighted)

• Deep Concept Explanation (beyond NCERT but CBSE aligned)

• Neat Labeled Diagrams (clean academic style)

• Important Points for Board Exams (bullet format)

• Common Mistakes Students Make

• Answer Writing Tips for Full Marks

• Previous Board Exam Style Question with Ideal Answer

Notes must be neat, precise, structured, diagram-friendly, and high-scoring.

Do NOT create short and long notes separately. Only perfect exam notes.
